# 📝 Simple HTML and CSS Form

This is a practical project developed to consolidate web structuring fundamentals, focusing on creating interactive forms using semantic HTML and basic styling.

---

## 🚀 Technologies Used

* **HTML5:** Proper structuring of form tags and elements (`<form>`, `<input>`, `<label>`, `<button>`, etc.).
* **CSS3:** Visual styling, element alignment, and interface refinement.

---

## 💡 Concepts Practiced

* Creation and organization of data input fields (text, email, etc.).
* Use of associated labels (`labels`) to ensure good accessibility and semantics.
* Clean web page structuring within the front-end ecosystem.

---

## 📁 How to View

1. Download or clone this repository to your computer.
2. Open the `index.html` file directly in any web browser of your choice.

# 📝 Formulário Simples em HTML e CSS

Este é um projeto prático desenvolvido para consolidar os fundamentos de estruturação web, focando na criação de formulários interativos utilizando HTML semântico e estilização básica.

---

### 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação correta das tags e elementos do formulário (`<form>`, `<input>`, `<label>`, `<button>`, etc.).
* **CSS3:** Estilização visual, alinhamento de elementos e refinamento da interface.

---

### 💡 O que foi praticado

* Criação e organização de campos de entrada de dados (texto, email, etc.).
* Utilização de rótulos (`labels`) associados para garantir boa acessibilidade e semântica.
* Estruturação limpa de páginas web no ecossistema front-end.

---

### 📂 Como Visualizar

1. Faça o download ou clone este repositório para o seu computador.
2. Abra o arquivo `index.html` diretamente em qualquer navegador web de sua preferência.
